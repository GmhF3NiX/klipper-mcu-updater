"IN ORCASLICER ÖFFNEN" nutzt das orcaslicer://open?file=…-Protokoll, das die OrcaSlicer-Desktop-App auf Windows/Mac registriert (dasselbe, was Printables' "Open in Slicer" nutzt) — OrcaSlicer muss installiert und einmal gestartet worden sein, dein Server muss im selben Netz erreichbar sein. Auf manchen Linux-Distros (v. a. KDE) ist die Protokoll-Registrierung unzuverlässig — dann hilft nur DOWNLOAD + manuell in OrcaSlicer importieren.
KOSTEN-SCHÄTZUNG (Faustformel, kein echtes Slicing)
Filament- und Zeitschätzung aus Modellvolumen/-oberfläche + Druckprofil (Schichthöhe, Fülldichte, Wände, Geschwindigkeit, Drucker-Watt). Filamentgewicht ist brauchbar genau, die Druckzeit ein grober Richtwert — für echtes Slicing "IN ORCASLICER ÖFFNEN" oben nutzen.
DRUCK-KOSTEN
Strom kommt von deinem Home-Assistant-Energiesensor für den Zeitraum zwischen Start und Stop (Einstellungen über das ⚙-Symbol oben rechts). Filamentgewicht trägst du manuell ein — Preis/kg kommt automatisch von Spoolman, sobald du eine Spule auswählst.

DRUCKPROFILE

NEUES PROFIL ANLEGEN
Dichte/Preis werden nur genutzt, wenn beim Berechnen keine Spoolman-Spule ausgewählt ist — sonst kommen beide automatisch von der Spule. Overhead-Faktor gleicht Reise-/Beschleunigungs- /Retract-Zeit pauschal aus (1.3 = Rohzeit + 30%).

BIBLIOTHEKS-ORDNER

NEUEN ORDNER HINZUFÜGEN
Der Container sieht read-only den kompletten Unraid-Share-Baum unter /mnt/user — gib hier den Pfad relativ dazu an (z.B. für /mnt/user/warez/3d-modelle also warez/3d-modelle). Der Ordner wird beim Hinzufügen sofort eingescannt und erscheint als eigener Top-Level-Ordner im Baum links.

DUPLIKATE

Vergleicht Dateien per SHA-256-Inhalts-Hash (nicht nur Name/Größe). Der erste Scan liest dafür einmalig jede Datei komplett — bei 1000+ Dateien kann das ein paar Minuten dauern, läuft im Hintergrund weiter, spätere Scans prüfen nur noch neue Dateien. Gefundene Duplikate werden nur angezeigt — die App liest deine Bibliothek nur, löscht nichts.

EINSTELLUNGEN

Token erstellst du in Home Assistant unter deinem Profil → "Long-Lived Access Tokens" → "Token erstellen". Der Sensor muss ein kumulativer Energiezähler sein (device_class: energy, state_class: total_increasing), z.B. der einer Zigbee-Steckdose am Drucker.
Optional. Wenn gesetzt, kannst du beim Druck eine Spule aus Spoolman auswählen — Preis/kg wird automatisch übernommen und der Verbrauch nach dem Speichern auf die Spule gebucht. Leer lassen für rein manuelle Filamentpreise.
